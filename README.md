# HACS208c

Material to support HACS 208c lecture on AI bias

## Data
- ` _train.csv` is a random sample of 80\% of the data from `https://github.com/propublica/compas-analysis/blob/master/compas-scores-raw.csv` 
- `_test.csv` is a random holdout sample of the remainder of the data


## Notebook
- ` .ipynb` is a notebook template to train a model on the COMPAS data

## Scripts
- ` .py` is the script used to split the original data
